# Shadow Monarch (Solo Leveling) — Forge 1.14.4

## Install
1. Install **Minecraft Forge 1.14.4-28.2.26** (the plain game / the OptiFine repack has no Forge).
2. Put `shadowmonarch-1.14.4-1.0.0.jar` in the `mods` folder.
3. Do not play on Peaceful (monsters are removed there).

## How it works
- A new world starts the **System** automatically: Level 1, no shadows, first quest.
- HUD (top-left): level/rank, XP, MP, current quest. Commands: `/sm status`, `/sm key`, `/sm leave`.
- Every few levels (5,10,15,20,25,30,40) growth is blocked until you beat that level's **Gate Master**
  (Goblin Chief, Fang, Cerberus, Tank, Iron, Igris, Beru) with the *Gate Master's Key* -> **Rank Up** (big power jump).
- **Gates**: right-click a Gate Key (E..S) to enter a sealed dungeon, kill everything, get rewards + quest credit.
  Keys are quest rewards and craftable from Magic Stones.
- **Shadows**: killing Fang / Tank / Iron / Igris / Beru unlocks their shadow.
  `K` = summon/dismiss equipped shadows (costs MP). `L` = Shadow Army menu (equip max 2, upgrade with Magic Stones).
  Shadows attack monsters and whatever you hit (animals only after you hit them).
- MP regenerates over time, faster when standing still, when well fed, and while sleeping; eating restores MP; Mana Crystals restore it instantly.
- OP test commands: `/sm setlevel n`, `/sm setrank n`, `/sm quest n`, `/sm unlock <fang|tank|iron|igris|beru>`.

## Build
Pushed to GitHub, the workflow in `.github/workflows/build.yml` builds the jar (Java 8 + Gradle 4.10.3 + ForgeGradle 3).
Textures/models/lang are generated by `python3 tools/gen_assets.py` (already committed).
